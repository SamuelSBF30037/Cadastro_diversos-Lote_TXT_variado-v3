# Cadastramento SICAD - Lote

**Versão:** 3.0 (Localizada na subpasta `ext_novo`)

**Descrição**
Extensão para o cadastramento em lote no SICAD com texto individual por RG/registro.

**Sobre**
Facilita o processamento massivo de informações inserindo dados no sistema SISP de maneira automatizada, processando informações individualizadas por usuário.
